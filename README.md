# Кинематографичный сайт автосервиса

Одностраничный сайт: тёмный, технологичный, с фильмом, который проигрывается
прокруткой. React + Vite + GSAP ScrollTrigger.

## Запуск

```bash
npm install
npm run dev
```

Откроется на `http://localhost:5173`.

Сборка и просмотр готовой версии:

```bash
npm run build
npm run preview
```

Готовый сайт кладётся в папку `dist`. Её содержимое и есть то, что
загружается на хостинг.

## Что менять и где

Весь текст, телефон, адрес, график, список услуг и пути к картинкам лежат
в одном файле: **`src/data/site.js`**. Вёрстка ничего не хардкодит, поэтому
правки делаются только там.

### Логотип

Сейчас на месте логотипа стоит нейтральный контейнер `[ ЛОГОТИП ]` того же
размера, что займёт настоящий знак. Когда он появится:

1. положите файл в `public/assets/`;
2. в `src/data/site.js` укажите путь в `BRAND.logoSrc`.

Структура и размеры не изменятся, шапку и подвал трогать не нужно.

### Данные-заглушки

Помечены в `src/data/site.js` словом PLACEHOLDER и на сайте поданы именно
как временные:

- телефон `+7 (999) 123-45-67`
- график «Ежедневно с 9:00 до 21:00»
- адрес «Нижний Новгород, ул. Примерная, 1»

### Медиа

- `public/assets/hero-scrub.mp4` — фильм под всей страницей
- `public/assets/hero-poster.webp` — первый кадр, он же неподвижный фон
  на телефонах
- остальные `.webp` — кадры для секций

**Пара «ДО / ПОСЛЕ» — временная.** Сейчас там два кадра из того же видео:
колесо на месте и снятое колесо с открытым тормозным узлом. По композиции
они совпадают и слайдер работает как надо, но это не результат ремонта.
Замените `before.webp` и `after.webp` на реальные фотографии одной детали
до и после работы, снятые с одной точки.

### Замена видео

Новое видео нужно перекодировать под скрабинг, иначе прокрутка будет
дёргаться: браузер умеет точно перематывать только на ключевые кадры.

```bash
ffmpeg -i исходник.mp4 -c:v libx264 -crf 22 -preset slow -g 8 -keyint_min 8 -sc_threshold 0 -pix_fmt yuv420p -movflags +faststart -an -vf "scale=1600:-2" public/assets/hero-scrub.mp4
```

После замены обновите в `src/data/site.js` поле `MEDIA.heroVideoBytes` —
реальный размер файла в байтах. Длительность подставляется сама: страница
считает время от прогресса прокрутки, а не от секунд.

Важно: новое видео должно идти от «собрано» к «разобрано». Обратный ход
второй половины страницы приводит именно к первому кадру, и в финале должна
оказаться готовая машина.

Постер пересобирается так:

```bash
ffmpeg -i public/assets/hero-scrub.mp4 -frames:v 1 -c:v libwebp -quality 82 public/assets/hero-poster.webp
```

## Проверка качества

```bash
npm run preview        # в одном окне
node tools/audit.mjs http://localhost:4173
```

Проверка гоняет настоящий браузер и смотрит девять вещей: ход фильма туда
и обратно по всей странице, пейсинг реплик рывками колеса, контраст текста
поверх видео по худшему кадру, ошибки консоли, поведение при
`prefers-reduced-motion`, работу страницы без видео, слайдер с клавиатуры,
вес и скорость, выход за границы на семи ширинах.

Скриншоты всех секций на десктопе и телефоне:

```bash
node tools/shoot.mjs http://localhost:4173
```

Папка `tools` в сборку не попадает.

## Как устроена страница

Фильм лежит закреплённым слоем под всей страницей, а секции скользят
поверх него. Прокрутка гонит время видео **туда и обратно**:

```
верх страницы      середина          низ страницы
кадр 0 с    →      кадр 10 с    →    кадр 0 с
машина цела        разобрана         снова собрана
```

Исходное видео идёт от целой машины к разобранной, поэтому обратный ход
сам приводит к нужному финалу: под телефоном в конце страницы стоит
собранный автомобиль.

Порядок содержимого:

```
01  Первый экран, слоган
    окно: РАЗБИРАЕМ ДО СУТИ
02  Что мы делаем
    окно: СМОТРИМ ГЛУБЖЕ
03  Видим главное
    окно: ИЩЕМ ПРИЧИНУ
04  До и после
    окно: УСТРАНЯЕМ ПРОБЛЕМУ
05  Контакты
```

Окно — участок страницы без содержимого, где фильм виден целиком и в одном
из углов стоит короткая реплика. Реплики лежат в `FILM_CAPTIONS`
(`src/data/site.js`), там же задан угол кадра для каждой: углы намеренно
разные, чтобы взгляд не залипал в одной точке.

Секции над фильмом полупрозрачные, кадр сквозь них просвечивает. Плотность
задана в `global.css` у `.section`; секция контактов помечена
`.section--open` и пропускает фильм целиком.

**Под надписями кадр не затемняется.** Видео здесь главное, поэтому вместо
подложек работает плотная короткая тень вокруг самих букв плюс небольшое
мягкое пятно, которое чуть больше строки и гаснет к своим краям. Постоянная
цветокоррекция кадра тоже есть, но она одинаковая на всём фильме и не
реагирует на появление текста.

## Инженерная часть скраба

Ключевое:

- видео тянется целиком как Blob, потому что многие хостинги молча не
  поддерживают частичную загрузку, и без этого перемотка на живом сайте
  не работает при исправной работе локально;
- отображаемое время догоняет целевое плавно, с поправкой на частоту
  кадров экрана;
- новая перемотка не отправляется, пока не завершилась предыдущая;
- в DOM пишется только то, что изменилось.

На телефонах, планшетах в портретной ориентации и при включённом
`prefers-reduced-motion` вместо фильма показывается неподвижный кадр,
окна с репликами не выводятся, а видео не скачивается вообще.
