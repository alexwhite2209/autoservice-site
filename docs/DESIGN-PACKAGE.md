# Design Package — кинематографичный сайт автосервиса

Единый документ решений. Пишется до генерации, потребляется сборкой.
Вся копия ниже уходит в вёрстку дословно.

---

## 1. Премиса бренда

Одна идея, на которой держится вся страница: **причина, а не симптом**.

Сайт не продаёт «ремонт». Он продаёт точность постановки диагноза: сначала
находим, потом устраняем. Отсюда весь визуальный язык — техническая графика,
подсветка узлов, рентгеновский разрез автомобиля, сравнение «до/после».
Каждая секция служит этой идее, иначе её нет на странице.

Названия бренда нет. Логотип — нейтральный placeholder-контейнер `[ ЛОГОТИП ]`
в шапке и подвале, заменяется одной константой без изменения вёрстки.

## 2. Палитра как CSS-токены

Задана брифом, не выдумывается. Красный — редкими дозами.

```css
:root{
  --canvas:        #080808;  /* основной фон, не чистый чёрный */
  --canvas-2:      #101010;  /* вторичный фон, чередование секций */
  --panel:         #151515;  /* панели, поднятые поверхности */
  --text-primary:  #F2F2F2;
  --text-secondary:#A0A0A0;
  --accent:        #FF2B1A;  /* CTA, номера секций, активные точки */
  --accent-hover:  #FF4433;
  --accent-muted:  rgba(255,43,26,.16); /* свечение, границы шёпотом */
  --hairline:      rgba(242,242,242,.10);
  --hairline-strong: rgba(242,242,242,.22); /* интерактивные границы, 3:1 */
}
```

Где красный появляется, и больше нигде: кнопка «ПОЗВОНИТЬ», активный номер в
индикаторе секций, слово «УСТРАНИЛИ.», номера секций, линия под заголовком,
точки диагностики, hover услуг, подпись «ПОСЛЕ», focus-состояния.

## 3. Шрифтовое трио

Все три с полной кириллицей, иначе на русском сайте они бесполезны.

- **Display: Onest** 800/900 — современный гротеск, разработан под кириллицу.
  Заголовки крупные, uppercase, трекинг −0.03em. Не Inter и не Roboto.
- **Body: Golos Text** 400/500 — тихая наборная пара, кириллица от Paratype.
- **Mono: JetBrains Mono** 400/500 — номера секций, HUD-подписи, мелкие метки.

Характер задаётся не причудами шрифта, а обращением: огромный кегль, плотный
трекинг, много воздуха, один красный акцент. Так делают премиальные
автомобильные бренды, и для «строго и дорого» это точнее вычурной гарнитуры.
Сознательное отклонение от совета скилла «display с характером» — сказано вслух.

## 4. Карта полос hero (band map)

Hero — закреплённая (pinned) область, прокрутка внутри неё гонит время видео.
Длина области подбирается под длительность фильма: ~450vh на 6 секунд,
~550vh на 10. Точные диапазоны — стартовые точки, проверяются flick-тестом.

| Полоса | Диапазон | Момент фильма | Копия (дословно) | Вход |
|---|---|---|---|---|
| 1 | 0.00 – 0.66 | Автомобиль в тёмном боксе, камера медленно идёт вперёд | «НАШЛИ / ПРОБЛЕМУ, / УСТРАНИЛИ.» + «Точная диагностика. / Профессиональный ремонт.» | Word-by-word rise, ступенчатый settle; полоса 1 собрана уже на загрузке |
| 2 | 0.00 – 0.14 | Начало проезда | «ПРОКРУТИТЕ ВНИЗ» + индикатор | Мягкое проявление, уходит при первом же скролле |
| 3 | 0.70 – 1.00 | Прибытие к передней части, кадр останавливается | Прозы нет: технический HUD — номера, перекрестие, линия сканирования | Прорисовка линий по `--k` |

**Почему полос всего три и почему в них нет прозы.** Бриф запрещает выдуманные
преимущества и лишние слоганы. Поэтому фильм несёт себя сам, а поверх него
живёт только санкционированный брифом текст и чистая техническая графика без
слов. Это осознанное решение, а не экономия.

## 5. Статичный hero (телефоны, reduced-motion)

Композиция на кадре-постере, без прокрутки под ней:

- «НАШЛИ ПРОБЛЕМУ, УСТРАНИЛИ.» — «УСТРАНИЛИ.» красным
- «Точная диагностика. Профессиональный ремонт.»
- Кнопка «ПОЗВОНИТЬ» → `tel:+79991234567`

## 6. Секции после settle

Порядок и копия — дословно из брифа, ничего не добавляется.

**02 — ДИАГНОСТИКА.** «Компьютерная диагностика всех систем.» /
«Находим причину неисправности, а не меняем детали наугад.»
Визуал: тёмный кадр механика с диагностическим прибором.

**03 — ЧТО МЫ ДЕЛАЕМ.** «Решаем проблемы любой сложности. Быстро. Честно.
С гарантией.» Крупный вертикальный список из четырёх строк, не карточки:
01 ДИАГНОСТИКА, 02 ДВИГАТЕЛЬ, 03 ХОДОВАЯ, 04 ТОРМОЗНАЯ СИСТЕМА.
Электрики нет.

**04 — ВИДИМ ГЛАВНОЕ.** «Современное оборудование позволяет точно определить
неисправность.» Рентгеновская SVG-визуализация автомобиля, рисуется вручную,
четыре красные точки с выносками: ДВИГАТЕЛЬ, ХОДОВАЯ, ТОРМОЗА, ДИАГНОСТИКА.
**Это подписанный элемент сайта** — весь бюджет смелости уходит сюда.

**05 — ДО И ПОСЛЕ.** «Наглядный результат нашей работы.» Интерактивный
слайдер сравнения, мышь + touch + клавиатура. Подписи только «ДО» и «ПОСЛЕ».
**Это designed interactive moment**: посетитель сам выполняет то, что продаёт
страница — смотрит на результат до и после.

**06 — КОНТАКТЫ.** «ЧТО-ТО / НЕ ТАК?» / «Позвоните нам. Разберёмся.» /
«ПОЗВОНИТЕ ПРЯМО СЕЙЧАС» / «+7 (999) 123-45-67» / «Ежедневно с 9:00 до 21:00».
Формы нет вообще. Единственный CTA страницы — звонок.

**Подвал.** `[ ЛОГОТИП ]`, навигация О НАС / УСЛУГИ / КОНТАКТЫ, адрес
«Нижний Новгород, ул. Примерная, 1», «© 2026». Всё это placeholder-данные,
и на странице они поданы как placeholder, а не как реальные сведения.

## 7. Векторный слой

Рисуется руками, не берётся готовым:

- Рентгеновский автомобиль в секции 04: контур кузова, двигатель, подвеска,
  тормозные диски. Прорисовка через `stroke-dasharray` по скроллу.
- Выноски от точек к подписям — тонкие ломаные линии, рисуются последовательно.
- HUD-рамка поверх hero: перекрестие, угловые засечки, линия сканирования.
- Разделители секций — самопрорисовывающиеся горизонтальные линии.
- Фоновый слой на всю страницу: очень медленный дрейф зерна, цикл 60с+.

Всё уважает reduced-motion: конечные состояния показаны, приводы остановлены.

## 8. Инженерный список

Полный стандарт `scrub-pipeline.md`, ничего не пропускается:

- загрузка видео через Blob (обход отсутствия HTTP Range), кольцо прогресса
  для файлов тяжелее ~8 МБ, watchdog на 20с;
- lerp отображаемого времени в rAF-цикле, нормализованный по dt, засыпает
  при сходимости и вне экрана;
- шлюзование seek: никогда не писать `currentTime` поверх незавершённого
  seek, коалесценция к новейшему, сброс флага по `error`;
- запись в DOM только по изменению, дельта-гейт 0.008;
- пейсинг полос в vh, проверка flick-тестом 120/240/360px;
- четырёхслойная система читаемости текста поверх видео, аудит худшего кадра
  ≥3.5:1;
- пять шлюзов статичного hero, живые слушатели `change` на всех пяти;
- страница полна и красива, если видео не загрузилось вовсе;
- reduced-motion в обе стороны, live.

Стек: React + Vite + GSAP ScrollTrigger, компоненты по §31 брифа.
**Отклонение от скилла сказано вслух:** `10k-websites` требует один
`index.html` без сборки, но бриф прямо просит React/Vite и разбиение на
компоненты Header/Hero/Diagnostics/Services/TechnicalCar/BeforeAfter/
Contact/Footer/SectionIndicator. Бриф пользователя главнее. Инженерный
стандарт scrub-конвейера при этом соблюдается полностью.

## 9. Копирайт-шлюз

Вся копия выше уходит в вёрстку дословно. Готовая страница обязана пройти
проверку: ноль длинных тире, ноль штампов, ноль английских элементов
интерфейса, только «ДО»/«ПОСЛЕ». Плейсхолдеры остаются плейсхолдерами.
